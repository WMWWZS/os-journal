# Notes · 零散笔记

> 系统的知识放 `docs/`，这里放**还没想清楚的东西**。

## 什么该放这里

- 一次「本以为…结果…」的观测：计数器读数、现象、第一反应
- 某个数字和教科书不一致时的排查过程
- 踩坑记录：工具不可用、权限被拒、单位换算错
- 一句还不成熟的结论（标记「待验证」）

**不放这里**：能整理成体系的知识（→ `docs/`）、完整实验步骤（→ `labs/`）。

## 命名规则

```text
YYYY-MM-DD-简短标题.md
```

例如：

```text
2026-11-23-first-touch-400ns.md
2026-11-24-nt-prefix-is-not-a-syscall.md
```

## 模板

复制 [`_TEMPLATE.md`](_TEMPLATE.md) 开始写。六段必须写全：**现象 → 原始输出 → 第一反应 → 实际原因 → 证据 → 结论**。
